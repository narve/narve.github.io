This is a fully standalone HTML page. Open it directly in a browser and it works as a complete document.

When Eleventy builds the site, the custom .html extension:

  1. Reads <title>, <meta name="description">, <meta property="article:published_time">, and all <meta property="article:tag"> entries as front matter.
  2. Extracts the inner HTML of #blog-content as the post body.
  3. Wraps it in the site layout — so you also see the site header, footer, and styling at the published URL.

Everything outside #blog-content is invisible to the SSG.
